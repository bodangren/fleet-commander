# Proposed Lessons-Learned Additions (from Graph Node Audit, 2026-06-02)

> These are proposed for review before being merged into `measure/lessons-learned.md`. Each entry follows the `(tag) Description` format used by the current file.

- (track_closeout) A "wired into the orchestrator hot path" claim in plan.md must be backed by an integration test that runs in production code, not in the test file alone — the audit found 8+ pivot exports (RecoveryDispatcher, WorktreeManager, applyBudgetPenalty, etc.) that are unit-tested but never imported outside their test file
- (dual_implementations) When a track replaces a subsystem, archive the old one in the same commit — the audit found 6 parallel-implementation pairs (MarkdownEditor/MarkdownViewer, legacy/new KanbanBoard, AnalyticsDashboard/AnalyticsPage, CostDashboard/CostsPage, PerformanceDashboard/PerformancePage, convexClient/typedConvexClient) all left in the same tree
- (jtdoc_propagation) Never copy-paste JSDoc across sibling exports — `useConvexData.ts` has 30+ hooks with the same `Subscribe to a Convex query imperatively` docstring, and `useConvexRealtime.ts:207` has a `hook hook` typo from copy-paste
- (orphan_detection) "Tested via X" in plan.md must mean X actually exercises the code in production, not that a test file exists — 21 of 27 pivot route files have sibling test files that contain 0 nodes; the test-file-exists invariant is misleading
- (stub_mutations) Stub mutations that return `null` / `args` without writing must be removed or labeled with `// TODO(track-id):` and a `@deprecated` JSDoc — `scoreAudit.createScoreAudit`, `dispatchPolicyStats.upsertDispatchPolicyStats`, `migrate.migrateSimplifiedSchema`, `seed.seedDemoData` all return args without inserting and are public API
- (concurrent_auth) Never combine an `anonymous-bootstrap` fallback with a missing `auth.config.ts` — Convex's `ctx.auth.getUserIdentity()` returns `null` in every environment when `auth.config.ts` is absent, so the bootstrap becomes the only path and every public mutation is anonymously callable
- (parallel_systems) Two parallel subsystems (e.g. `runProject` SDK path vs `runSchedulerTick` CLI path) implementing the same domain will silently drift in retry policy, schema, and execution mechanism — declare one canonical path in `measure/specs/canonical-implementations.md` before introducing a second
