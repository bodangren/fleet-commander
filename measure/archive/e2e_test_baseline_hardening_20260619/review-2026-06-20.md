## Code Quality Observations

- **Good:** `seed.ts` is small (44 lines), narrowly scoped, and composes the existing mock helper rather than duplicating it. Contract tests are static-analysis based and run fast via Vitest.
- **Good:** `doctor.sh` `--dry-run` is implemented correctly and bounded to `frontend/e2e/smoke.spec.ts`, preventing accidental full-suite execution in the test harness.
- **Concern:** `mockApp.ts` was changed late in the cycle to make `projectList` mutable and `usePortfolioData` return a `refresh` callback. This is a real production hook change driven by E2E test needs; while small, it couples E2E hardening to frontend data-flow changes and should be reviewed for blast radius.
- **Concern:** `DashboardPage.tsx` receives a hard-coded `data-realtime-ready="true"` attribute on its outer `div`. The attribute is set unconditionally whenever the component renders, so it does not truly signal "subscription ready" for the Convex path; it works for the mock-adapter path used by Playwright but is a testing-only hook in production code.
- **Style:** Prettier warnings remain on the Red-authored contract test files; `bun --cwd frontend check` exits 1 on formatting. This is documented as pre-existing but degrades the local verify gate.

## Risks or Blockers

1. **E2E version collision.** The worktree has two `@playwright/test` versions (root v1.59.1 vs. `frontend/` v1.60.0). `npx playwright` resolves the stale root copy, causing duplicate-version errors. The track notes the workaround (`frontend/node_modules/.bin/playwright`) but does not fix the dependency root cause.
2. **Selector drift is structural.** 17 selector-drift failures and multiple smoke/kanban failures indicate the specs reference UI text/buttons that no longer exist. Fixing this requires either updating specs to match the current UI or accepting partial coverage.
3. **Task 7 closeout rationale is contradictory.** Multiple commits oscillate between `[~]` and `[x]` for Task 7. The final closeout marks it `[x]` with the rationale that 32 failures are triaged to Phases 2–3, but those phases were already closed, leaving no owner to actually fix them.
4. **Frontend test timeouts.** `bun --cwd frontend test --run` times out at 300s on 16 pre-existing failures across 8 unrelated spec files, making the local frontend verify gate unreliable.
